# Vela Android Native UI Skill 使用说明

## 这是什么

这是一个面向 AI Agent 的 Skill，用来指导小米 Vela OS JS 快应用（`.ux`）的界面设计与实现。它既可以用于控件示例库，也可以帮助构建天气、运动、社交、搜索和工具类应用的 UI。它不包含这些业务所需的服务端、真实数据 API 或账号系统。

Skill 可脱离示例工程独立使用：提供需求和现有工程后，Agent 可按文档构建界面；`demos/` 则是可选的源码参考与可修改起点。

## 下载

- GitHub 项目：<https://github.com/midi-HL/xiaomi-vela-android-ui-skill>
- 最新发布页（含 Skill ZIP 和 RPK 示例）：<https://github.com/midi-HL/xiaomi-vela-android-ui-skill/releases/latest>
- ZIP 也保存在仓库的 `releases/vela-android-native-ui.zip`。

## 安装

解压后保持以下结构，不要把 `SKILL.md` 单独从资源目录拆开：

```text
vela-android-native-ui/
├── SKILL.md
├── references/
└── assets/
```

将整个 `vela-android-native-ui` 文件夹放到 Agent 所支持的 Skills 目录。Codex 可使用用户级目录 `~/.agents/skills/vela-android-native-ui/`。安装或更新后，让 Agent 重新扫描 Skills（通常重启 Codex 即可）。

## 适用范围

- 小米 Vela JS 快应用原生 UI，页面使用 `.ux`。
- 可复用组件、主题与设置、字号偏好、页面模板、输入法资源、手环/手表多形态布局。
- 帮助 Agent 检查路由、存储、设备适配和构建产物。

Lua 表盘、LVGL 或 NuttX Shell 开发不属于本 Skill 的主范围；请搭配 `vela-quickapp-dev` 中相应指南。Skill 也不会替代官方 SDK 文档或目标设备验证。

## 如何使用

1. 在支持 Agent Skills 的 AI 助手中安装本 Skill。
2. 提出具体 UI 目标，并提供已有工程或说明应用类型、目标设备形态和交互要求。
3. Agent 先读取 `SKILL.md`，再按任务读取 `references/` 中的主题、组件、页面或构建说明。
4. `assets/components/` 中的组件可复制到项目；Demo 工程可用来了解组件如何组合。
5. 若要生成可安装包，按 `references/build-and-validation.md` 配置 Vela AIoT 工具链并构建。打包成功不代表真机视觉和交互已经验证，应在目标设备上实际检查。

## 仓库目录

- `vela-android-native-ui/`：完整 Skill。ZIP 内也保留同样目录和相对路径。
- `components/`：便于单独查看和复制的组件副本。
- `demos/`：四种设备形态的示例源码工程。
- `releases/`：Skill ZIP 与各形态编译的 RPK 示例。
- `docs/示例包说明.md`：RPK 内容、设备形态、安装与验证注意事项。
