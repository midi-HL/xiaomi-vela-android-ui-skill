# 小屏布局、列表与交互验收

## 列表必须可滚

- 重复条目用 Vela 原生 `<list bounces="true">` 与 `<list-item for="..." type="...">`。明确写 `width`、每种 type 的 item `height`；页面是固定视口高度的纵向 flex 时，list 使用 `flex:1` 填充剩余高度，避免不同设备复用固定视口高度导致底部留大片空白或设置行不可达。若父布局无法计算剩余空间，才设置显式 list 视口高度。同一 type 的子节点树保持一致。
- 控件展示 Demo 的设置页主题和外观选项作为 list 中连续的同级 item 排列；每个整行卡片只在 list-item 宿主绘制一次 surface 底色，内容直接排在宿主内或使用透明布局容器，不叠一张同尺寸内层卡片；其首页显示设置入口也是同级列表项，不固定在列表外的底栏。一般应用按自身信息架构安排设置入口，但重复选项使用可滚动原生列表。
- `<scroll>` 用于一块复合内容；设 `scroll-y="true"`、确定视口高度，只放一个直接内容根节点。不要同时让内容根节点和滚动视口无界 flex 拉伸。
- 在设备上从列表中央连续上下滑动，确认首末行均可见；再点击各行，确认点击和纵向滚动不互相吞事件。

## 字体和小屏排版

- Demo 统一时间字号为 20px、页面标题为 18px；先在目标屏幕验证，再按安全区微调。首屏必须给主要内容留足垂直空间。
- 为文本定义角色令牌。字号偏好只绑定到用户明确指定的正文/长说明角色；其余界面文字保持固定。除非产品明确要求，不要随字号改变控件尺寸。时间 20px、页面标题 18px、区块标题 16px、卡片/条目标题 14px、正文 12px、辅助字 10px；允许可调长说明映射为 10/11/12px，其他 UI 标签、时间、标题、状态短字使用固定角色字号；图标 20/24px。相同角色在所有形态字号一致，媒体查询不得改变字号。不要在时间、标题上直接绑定正文的 `baseFont` / `largeFont`。
- 避免用固定高度裁切多行 text。每个文字盒都检查字号、line-height 和父容器高度；短标签可按需要截短；首页、分类行与详情中的说明文字必须用可见 marquee，不能用省略号替代用户要求的跑马灯。卡片高度必须容纳标题、说明和预览三部分。
- 长说明使用 Vela 原生 `<marquee>`，控制在单行展示并限制滚动速度；若放在重复行模板，要确认目标 SDK 能正确启动每个实例。更稳妥的做法是在详情页使用唯一 id，在 `onReady` 调用 `this.$element('descriptionMarquee').start()`。短标签不要加 marquee。
- 用户明确提出跑马灯时，该局部滚动文字是对零动画默认的显式例外；不得扩展成页面转场或无关动效。
- 顶部只显示时间；不加占高的 hero、应用名或装饰遮罩。首页底部不放容易落入圆角黑边的装饰小字。

## 可操作控件示例

- 控件展示 Demo 的每个详情页必须实际渲染对应组件。自定义组件优先用唯一 alias（如 `ui-radio`），避免与平台标签同名。检查 `component.json` props 与 `index.ux` props/data 是否一致。
- 每个动态绑定到 CSS 几何尺寸的字段必须在 `data` 中有有效默认值；height、width、fontSize、padding 未初始化会产生空白/裁切组件。
- 组件内部只维护控件状态并 `$emit` 变化；父页监听 `@change`/`@click`、更新状态，并把新值绑定回 props。radio 示例需要互斥的两个选项；switch 点击不能同时触发外层和内层两次；slider 显示实时数值。
- 详情页需显示当前值/选择结果。若组件是只读展示（progress、banner 等），在页面说明其展示属性并使用有意义的示例数据。
- 对话框默认隐藏，由示例按钮打开；确认/取消由父页面关闭对话框并更新状态文案。

## 验收

1. 在每种目标屏幕截图首页、列表、设置和交互详情；检查安全边距、字形完整和主要信息密度。
2. 每个可滚动区域滑到末尾；控件 Demo 需确认显示设置与全部外观模式都能到达。
3. 控件 Demo 点每个分类并检查标题/计数/ID；点每个控件并操作，再确认状态文本或选中样式更新。一般应用验证关键业务路由和操作结果。
4. 调字号时只检查约定的可调正文改变，固定角色字号不变；测试最小和最大字号下的裁切与控件尺寸。
5. 切换主题/模式后验证首页、列表和详情，不只看设置页；返回和重启后再次确认状态。
6. 构建成功不代表手势、滚动、点击或视觉通过；没有设备实测就明确标记未验证。
