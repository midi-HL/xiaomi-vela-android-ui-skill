# 设备形态 Demo 工程

四个目录是彼此独立的 Vela 快应用工程，分别构建和验证。修改一种设备形态时，只改对应目录；不要把某一工程的页面 CSS 或设备形态媒体规则复制到其他工程。

- `runway-band9/`：小米手环 9 跑道屏。保持跑道屏页面规则，不加入圆屏或方屏覆盖。
- `runway-band10/`：小米手环 10 跑道屏。保持跑道屏页面规则，不加入圆屏或方屏覆盖。
- `square/`：方屏/宽屏设备的独立工程。
- `circle/`：圆屏设备的独立工程。

每个目录均有自己的 `src/`、`dist/`、`manifest.json` 和签名配置。需分别在目标模拟器/设备上验证，不能用一个形态工程的编译成功来代替其他形态的布局验证。
