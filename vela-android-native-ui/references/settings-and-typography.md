# 设置页与字号系统

控件展示 Demo 的设置页只包含字号、主题颜色、浅色/暗色/纯黑模式与一行关于信息。其他应用可按需求增加业务设置；重复选项仍放在单个可滚动原生列表，不嵌套互相抢手势的滚动区。

## Demo 字号角色标准

四个设备 Demo 使用同一套字号角色，不按屏幕形状任意覆盖同一角色。统一字号阶梯为 `10 / 11 / 12 / 14 / 16 / 18 / 20 / 24px`；禁止新加 9、13、15、17、19 等零散档。

| 角色 | 字号 | 使用范围 |
|---|---:|---|
| 辅助说明、计数、状态短值 | 10px | 标签、来源信息、轻量提示、计数 |
| 正文 | 12px | 控件内标签与一般说明 |
| 条目/卡片标题 | 14px | 控件列表项、预览卡片标题 |
| 区块标题 | 16px | 首页分组或设置分区 |
| 页面标题 | 18px | 二级分类名、详情名、设置页名 |
| 时钟、符号图标 | 20px | 顶部时间和功能符号 |
| 大型空状态图标 | 24px | 仅图形符号，不用于说明文字 |

相同角色在首页、分类页、详情页、设置页、组件样例及 Band 9/10、方屏、圆屏中保持同字号。不得在圆屏媒体查询中偷偷缩小文字；屏幕适配应改内容宽度、间距、卡片高度和滚动视口。标题大小按角色层级保持 `页面标题 > 区块标题 > 条目标题 > 正文 > 辅助说明`。

用户选择的 22/24/26 只作用在明确允许变化的长说明正文，统一映射 `22→10px、24→11px、26→12px`。固定标题、时钟、按钮、控件标签、预览标签、计数、状态标签和导航不得绑定偏好。所有 `<marquee>` 都要显式声明固定或映射后的 `font-size` 和高度；Vela 默认 30px，不能依赖默认值。短辅助语使用普通 `<text>`。

## 可调正文与固定界面文字

字号偏好采用 `bodyFont`，支持 22、24、26 三档。只把它绑定到产品明确允许调节的正文或较长说明，例如帮助说明、详情描述。窄屏不要把 22/24/26 直接当作可见 px；按设备做紧凑映射，例如 Demo 统一映射 22→10、24→11、26→12px，并检查行高。不要把偏好绑定到类别标题、卡片标题、按钮、控件标签、选项名称、计数、时间或导航。

以下角色使用独立固定字号，字号设置不得改变它们：时间、页面/区块标题、卡片标题、按钮文字、控件标签、选项名称、计数、图标和导航文字。示例和组件 API 应清楚区分 `bodyFont` 与固定字号令牌，禁止把 `bodyFont`、`largeBodyFont` 或其比例直接铺到所有 `<text>`。

字号变化只要求更新允许调节的正文文字，并检查其行高与容器是否容纳文字。控件高度、触控面积、间距和图标大小不因字号偏好自动缩放；只有产品明确要求这些几何随字号档位联动时，才按约定令牌单独联动几何，文字本身仍保持角色规则。

```js
const allowedFonts = [22, 24, 26]
this.bodyFont = allowedFonts.includes(next) ? next : 24
this.bodyCopyFont = this.bodyFont === 22 ? 10 : (this.bodyFont === 26 ? 12 : 11)
// 仅正文/长说明绑定映射后的 bodyCopyFont；按钮与标签保留固定字号
```

## 设置持久化

使用 `@system.storage`，不要使用浏览器 `localStorage`。推荐值为 JSON：`{themeId, modeId, bodyFont}`；校验主题、模式和字号白名单，坏数据回退到 `{blue, light, 24}`。主题和模式变化要同步到主页、列表、详情和设置页；字体变化只同步到允许调节字号的文本角色。画布主题也必须按 palette 更新：浅色背景使用轻微主题色底、卡片表面按主题使用浅色调，不统一为纯白；暗色背景和卡片是主题色调的深色表面；纯黑模式只有背景画布为纯黑，控件表面保留非黑深色层级。
