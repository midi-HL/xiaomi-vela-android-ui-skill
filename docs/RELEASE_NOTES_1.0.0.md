# Vela Android Native UI Skill 1.0.0

## Downloads

- `vela-android-native-ui.zip`: standalone Agent Skill archive. Extract with its top-level `vela-android-native-ui/` directory intact.
- `org.openvela.material.runwayband9.release.1.0.4.rpk`: runway-shaped Xiaomi Band 9 demo.
- `org.openvela.material.runwayband10.release.1.0.4.rpk`: runway-shaped Xiaomi Band 10 demo.
- `org.openvela.material.square.release.1.0.4.rpk`: square/rectangular-screen demo.
- `org.openvela.material.circle.release.1.0.7.rpk`: circular-screen demo; home layout is single-column.

The demos showcase 17 interactive UI controls, four categories, and settings for typography, theme, and appearance mode. RPKs are Vela quick-app packages, not Android APKs. Install with a compatible Vela/AIoT workflow on a matching virtual device or wearable.

## Validation

Release RPKs were produced by the AIoT Toolkit release command and their archive structure, manifest versions, pages, and packaged resources were checked. Device rendering is not certified for every model. In particular, the circular 1.0.7 layout should be checked on the target Watch S virtual device/device before treating it as visually validated. Band and square packages are earlier reference builds (1.0.4).

Sources and Chinese usage guides are in the repository README and `docs/`.
