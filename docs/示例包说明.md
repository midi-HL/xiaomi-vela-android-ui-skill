# Demo 示例包说明

## 包含什么

本项目提供四个 Vela JS 快应用源码 Demo 和对应的 release RPK 示例：

| Demo | 设备形态 | 包文件 | 当前包版本 |
|---|---|---|---|
| `runway-band9` | 小米手环 9 跑道形窄屏 | `org.openvela.material.runwayband9.release.1.0.4.rpk` | 1.0.4 |
| `runway-band10` | 小米手环 10 跑道形窄屏 | `org.openvela.material.runwayband10.release.1.0.4.rpk` | 1.0.4 |
| `square` | 方形/矩形屏参考布局 | `org.openvela.material.square.release.1.0.4.rpk` | 1.0.4 |
| `circle` | 圆形屏参考布局（Watch S/Redmi Watch 类） | `org.openvela.material.circle.release.1.0.7.rpk` | 1.0.7 |

Demo 展示 17 个可交互控件，分为按钮与容器、选择与调节、进度与状态、导航与辅助四类，并包含显示设置页（字号偏好、全局配色与外观模式）。不同设备形态的首页布局按各自工程实现。Skill 的组件模板和说明在 `vela-android-native-ui/`；RPK 只是可运行的展示应用，不是组件开发 SDK，也不包含用户自己的业务数据服务。

## 示例包怎么用

1. 从 GitHub 最新 Release 下载与设备形态匹配的 `.rpk`。RPK 是 Vela 快应用包，不是 APK。
2. 用小米 Vela/AIoT 官方工具或设备支持的安装流程，将包安装到匹配的模拟器或设备。
3. 启动“Vela Material UI”，浏览分类并进入控件详情；在显示设置里尝试字号、主题和外观模式。
4. 测试返回、列表滚动、主题持久化和具体控件交互。对设备实际显示效果，以目标设备测试为准。

如果需要修改 Demo，请下载或克隆源码项目中相应的 `demos/<形态>/` 文件夹，并按 `vela-android-native-ui/references/build-and-validation.md` 配置 AIoT 工具链后构建。仓库有意不提供签名私钥；如需自行签名，请使用自己的测试或发布密钥。

## 验证状态与限制

- RPK 文件已由 AIoT Toolkit release 流程生成，并在发布前核对包结构、版本字段和关键资源。
- 圆屏 1.0.7 根据 Watch S 虚拟设备截图修正首页为单列，并重新打包；该修正包仍需要用户在目标虚拟设备/手表上确认实际布局。
- Band 9、Band 10 和方屏示例包版本较早，是已编译的参考包；其打包成功不等于当前所有设备型号都完成了真机验收。
- 模拟器缩放、设备圆角/圆形裁切和平台版本会影响呈现。请勿仅凭 RPK 静态检查推断硬件显示正确。
- 安装失败时先核对目标设备是否支持该 Vela 平台版本与签名渠道；不要将 RPK 当作 Android APK 安装。
